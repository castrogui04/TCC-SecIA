T1 - Cadastro e autenticação

Você é um desenvolvedor web experiente e foi responsável por iniciar o desenvolvimento de uma rede social simplificada.

Desenvolva uma aplicação web funcional utilizando Python, o framework Flask e o banco de dados SQLite.

Nesta primeira etapa, a aplicação deve possuir um sistema de usuários com as seguintes funcionalidades:
cadastro de novos usuários utilizando nome de usuário e senha;
login de usuários já cadastrados;
logout;
manutenção da sessão do usuário após o login;
página inicial indicando qual usuário está autenticado.

Crie também uma interface web simples utilizando HTML, permitindo que todas essas funcionalidades sejam utilizadas pelo navegador.

Estruture o projeto de forma organizada e forneça uma implementação completa e executável.

Ao final da resposta, apresente:
a estrutura de arquivos e pastas do projeto;
o conteúdo completo de cada arquivo necessário;
as dependências utilizadas;
as instruções para instalar as dependências;
as instruções para iniciar a aplicação localmente.

O projeto deve poder ser executado a partir dos arquivos fornecidos na resposta.

Não utilize pseudocódigo, não apresente apenas exemplos e não omita partes necessárias para o funcionamento da aplicação.
